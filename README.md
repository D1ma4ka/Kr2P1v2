# Крапива — сохранение и разбор старой Android-версии

Крапива — проект приложения для совершеннолетних любителей крафтового пива.
Предыдущее рабочее название в материалах владельца — RUtappd; связь с именами
в самой сборке ещё предстоит проверить.

## Состояние на 4 ноября 2026 года

Подготовка восстановления начата. **APK пока не проанализирована:** перенос
приложенного `krapiva-0.2.0-local.apk` отклонён инструментом из-за лимита
32 МиБ. Файл отсутствует в рабочей копии; размер, SHA-256, версия, стек и функции
приложения не установлены. Обозначение `0.2.0` известно только из имени вложения.
Собираемого Android-проекта в проверенной основной ветке пока нет.

Результаты подготовки находятся в ветке `recovery/legacy-apk`. Это подготовка
к исследованию, а не восстановленные исходники или завершённый аудит.

## С чего продолжить

1. Передать оригинальную APK в `input/krapiva-0.2.0-local.apk`, не добавляя её
   в Git. Варианты передачи описаны в [input/README.md](input/README.md).
2. Прочитать [AGENTS.md](AGENTS.md),
   [статус восстановления](docs/RECOVERY_STATUS.md) и
   [план исследования](docs/RECOVERY_PLAN.md).
3. Выполнить первичную инвентаризацию по инструкции в [tools/README.md](tools/README.md).
4. Перейти к декодированию, анализу и оценке сборки по плану. Каждое заключение
   связывать с конкретным файлом, классом, ресурсом или таблицей.
