# APK для тестирования P1

По запросу владельца подготовлена для скачивания уже собранная новая debug APK.
Это отдельная ветка доставки, без новой сборки и без начала P2.

Файл: KraPiva-0.1.0-p1-debug.apk, 9353689 байт.
SHA-256: `e3fd6090533f0e6c3e991ee420f857caf84889ad328f95c4e189d079532b6b35`.
Android 8.0+, package `ru.krapiva.app.debug`, версия `0.1.0-p1`.

Откройте APK на телефоне и разрешите установку из используемого браузера
или файлового менеджера, если Android запросит это разрешение.
Тестируются запуск, splash, логотип/оформление, диалог «О KraPiva»,
прокрутка, поворот экрана и крупный системный шрифт.
Аккаунтов, каталога, базы данных и социальных функций пока нет.
На физическом устройстве эта APK ранее не проверялась.

APK не является релизом и хранится только в приватном репозитории.
Main и рабочая ветка разработки P1 не изменены.
