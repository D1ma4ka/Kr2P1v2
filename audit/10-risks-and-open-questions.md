# Риски и открытые вопросы

| ID | Вопрос / риск | Состояние и действие |
| --- | --- | --- |
| B-001 | APK недоступна для чтения | Лимит переноса 32 МиБ; нужен тот же оригинал в рабочей папке или полные бинарные части |
| Q-001 | Подтверждение оригинала | Получить размер и SHA-256; не выводить их из имени файла |
| Q-002 | Полнота установочного комплекта | После получения проверить манифест и возможные split-зависимости |
| Q-003 | Исходный проект и подпись | Исходники и приватный ключ подписи не обнаружены в проверенной ветке; наличие их у владельца пока неизвестно |
| Q-004 | Ограничения декомпиляции | Не обещать оригинальные Kotlin-файлы или собираемый проект до анализа |
| Q-005 | Данные, секреты и лицензии | Проверять извлечённые материалы перед выборочным импортом, сохранять уведомления |
| Q-006 | Динамическая проверка | Не выполнялась. Установка/запуск и перепаковка требуют отдельного согласования по AGENTS.md |
| Q-007 | Личные данные установленного приложения | Не трогать устройство и данные владельца; новый debug-ключ не заменяет исходный ключ |
| Q-008 | Git из терминала | Настроенный прокси недоступен; подключённый инструмент GitHub работает, ограничения не обходятся |

Выбор репозитория уточнён: использовать приватный `D1ma4ka/Kr2P1v2`.
Непроверенные функции не должны называться ни реализованными, ни отсутствующими.
