# Материалы старой версии

Извлечённых файлов здесь пока нет: исходная APK недоступна для анализа.

После исследования планируется выборочный импорт:

- `decoded/` — проверенные манифест и ресурсы;
- `decompiled/` — проверенное декомпилированное представление кода приложения.

Полные неизменённые результаты инструментов сохранять отдельно в `work/raw/<sha256>/`.
Не называть декомпиляцию оригинальными исходниками. Не включать сторонние
библиотеки, большие базы, фотографии или секреты автоматически. Уведомления
о лицензиях сохранять вместе с относящимися к ним материалами.

Каталог исключён из Git, кроме этого README. Перед выборочным добавлением файла
проверить содержимое, права публикации и размер; при необходимости явно
изменить точечные исключения `.gitignore` в том же коммите.
