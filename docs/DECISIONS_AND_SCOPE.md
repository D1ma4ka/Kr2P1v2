## Что не возвращать из старой версии

- Пакет `ru.penokrug.app.catalog` как основание новой Android-сборки и метод патчей `smali`, DEX, Apktool, повторная подпись старой APK.
- Старые GTIN, товары, иллюстрации, фотографии, встроенная read-only база и демо-карточки как публичный контент.
- Ботанический значок «Первый лист» и leaf-иконки в новом бренде.
- Локальную имитацию нескольких пользователей/общей ленты вместо реального API.

## Где решить неопределённости

1. Backend/SQL/storage/e-mail/VPS — ADR по технологиям и бюджету без покупки.
2. Гостевой режим, нижняя навигация, public/private по умолчанию — UX+privacy ADR.
3. Политика `BeerPosition` и дублей при отличиях объёма/типа тары — модель данных и модерационные правила.
4. Источники реально подтверждённых баров и пивных позиций — data governance.
5. 18+ / реклама / персональные данные / пользовательский контент — проверка требований законодательства перед production.
6. Конкретный домен, API-креденшелы, production SMTP, VPS и магазин — только после отдельного согласования и легитимного доступа.
