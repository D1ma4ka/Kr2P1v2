## Блокер B-001 — файл недоступен

Вложение называется `krapiva-0.2.0-local.apk`. Попытка переноса штатным
`download_file` завершилась ошибкой:

```text
file exceeds the executor transfer limit of 32 MiB
```

Из этого следует только превышение лимита 32 МиБ. Точный размер, SHA-256,
целостность ZIP, package name, версия, сертификат и функции **не установлены**.
Файла `input/krapiva-0.2.0-local.apk` в рабочей копии нет. Поиск другой сборки
и повторение той же заведомо неуспешной передачи не выполнялись.

Устранение: [варианты передачи того же оригинала](../input/README.md).
Первое действие после получения — SHA-256 и проверка комплектности, затем
первичная инвентаризация. Наличие вложения в чате не означает доступность его байтов.
