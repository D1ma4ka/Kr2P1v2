# P1 — clean foundation и дизайн

Дата: 2026-11-04. Ветка `codex/krapiva-2-p1`, основание `cf4d28a` (P0).
Владелец разрешил P1 сообщением «продолжай». **P2 не начат**.

## Объём

- Новый Android Kotlin/Compose/Material 3, minSdk 26, SDK 35; splash,
  стартовый экран, открытие/закрытие диалога «О KraPiva», safe areas,
  прокрутка, русские ресурсы и design tokens.
- Авторские SVG/PNG знака-пинты, геометрического lettering и стандартного
  аватара; adaptive/monochrome/launcher icons пяти плотностей.
- Node 24/TypeScript/Fastify HTTP server: config validation, liveness,
  реальные 404/400/413, ограничение body, безопасные request logs и SIGTERM.
- CI foundation: Android build/lint, backend build/tests/audit, source/assets
  guards. Pinned action SHAs, read-only permissions и конечные timeout.
- ADR по стеку и полной карте навигации; инструкции воспроизводимой сборки.

В активной ветке не было legacy: очистка NO-OP. AGENTS сохранён. Никаких
фальшивых операций auth/catalog/feed, seed/БД или импорта старого APK.
Стартовая UI-основа не выдаётся за реализацию S-01…S-22/A1…A12.

## Ошибки, исправленные до сохранения

- Первый TypeScript build отклонил обращение к unknown error; добавлено
  безопасное сужение типа. Тесты пройдены после исправления.
- Устаревающий disableRequestLogging заменён актуальным LogController.
- Первый Android lint выявил 7 ошибок: API27 theme attribute при minSdk26,
  backup rules, избыточный version qualifier иконок, unused colors и
  monochrome icon metadata. Исправлено без lint baseline/suppressions.
- Затем уточнены правила backup для API26–30: явные XML exclusions дополняют
  Android12+ data extraction rules. После финальной правки выполнена clean
  сборка/lint, 0 ошибок. Повторы запускались из-за конкретных исправлений.
