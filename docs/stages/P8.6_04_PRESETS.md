# P8.6.4 · Тематические и сохранённые фильтры

| Готовая подборка | Начальные условия |
|---|---|
| Тихая суббота | Бельгийское семейство, любой статус «Пробовал». |
| Хмелевой маршрут | Хмелевые эли, порядок по рейтингу. |
| Тёмная сторона | Стауты и портеры, доступна сортировка по крепости. |
| Кислая экспедиция | Кислые эли, включая Gose, Lambic и Berliner Weisse. |
| Охота за новым | Непробованные позиции любого стиля. Сначала совпадения существующего LocalDiscovery, а при нехватке данных используется рейтинг. |

Тема применяет исходное правило одним действием. Текущие условия можно менять в том же диалоге фильтрации, включая статус «Пробовал», и сохранять под новым именем. Встроенные темы определены в коде по устойчивым ID. Пользовательские правила имеют собственные UUID и сохраняют сортировку и все ограничения.

«Мои фильтры» поддерживают создание, изменение условий, переименование, копирование, удаление с подтверждением и быстрый выбор в другом месте. Одно пользовательское правило можно назначить по умолчанию для следующего открытия меню. Возврат из карточки сохраняет временные настройки. История показывает до восьми последних явно применённых тем и правил.

Шифрованный SQLite-документ `smart-bar-filters-v1` записывается атомарно через AccountApi и AccountStore с проверкой владельца. Формат хранит владельца, версию документа, UUID, версию правила, отметку обновления, признак удаления и параметры фильтра версии 1. Пересчёт выполняется по текущему меню. Списки позиций P8.4 живут в отдельном документе. Серверная синхронизация не подключена.

Автоматические тесты проверяют пять тем, приоритет совпадений и рейтинг при отсутствии персонального подбора, изменение правил, копию, удаление, default, историю, пересчёт между барами и неизвестные значения. Инструментальный тест проверяет сохранение в SQLite после закрытия хранилища, logout/login и привязку к двум аккаунтам. Фактические результаты запуска указаны в [передаче](P8.6_HANDOFF.md).
