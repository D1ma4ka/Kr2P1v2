## Решения, требующие проверки на следующем этапе

1. Нужны реальный поставщик первого ассортимента, допустимая атрибуция, ответственный модератор и порядок обновления. Пока их нет, в продукте показывать отсутствие публикации.
2. Одна редакция до 250 строк, ручная публикация модератором без цен и предлагаемые границы пяти тем — проектные решения. Сверить их на реальном меню до фиксации API. Определить собственный набор семейств стилей и ответственного за соответствия.
3. Весовые коэффициенты v1 проверяемы, качество подбора на реальном согласованном наборе ещё не оценено. Для согласованности при конкурентной правке дневника решить, достаточно ли двух страниц или требуется одно серверное чтение.
4. Остались независимая проверка на API 26/33+, сценарии двух аккаунтов, доступность, свежесть рейтинга и оценка числа запросов. Отчёт QA сам по себе не подтверждает закрытие этапа исправлений.

Следующему Codex при отдельной команде владельца: сверить удалённый HEAD этой ветки, локальные изменения и новые ветки, перечитать AGENTS, актуальное ТЗ и документы выше. Начинать с первого авторизованного пункта плана, сохранять API, выбор упаковки, данные P8.4 и идентичность выпуска в личной статистике. P8.6.1 заканчивается передачей документации.
