## План и границы

Порядок B: F1, F5, F9; C: F2; D: F3, F4, F6; E: F7, F8, F10;
F: общая стабилизация. F5→F2 подключается после появления репозитория подборок.
Каждая завершённая функция и стабильный длительный подэтап: отдельный commit,
push, затем сравнение HEAD с `git ls-remote` удалённой ветки. Без force-push,
merge/main, production, удаления данных и изменений backend-контрактов.

Новые данные хранятся в AccountStore: additive v3→v4, AES-GCM, owner scope;
старые таблицы/ключи не пересоздаются. Списки history хранят только ID и запросы;
карточки открываются через существующий API/TTL cache с действующими ACL.
Аналитика использует доступные собственные записи, не social cache; охват всегда
явно ограничен. Расчёты отделены от Compose. Sharesheet использует cache-only
FileProvider. Reminders opt-in, без выдуманных социальных событий.

Квота пятичасового/недельного лимита программно недоступна; проценты не выдумываются.
SDK/Gradle готовятся локально в ignored work. Signing config не меняется.
