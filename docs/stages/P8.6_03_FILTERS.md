# P8.6.3 · Фильтры опубликованного меню

Кнопка «Фильтры» открывает поиск по названию, выбор семейств и отдельных стилей с русскими/английскими синонимами, производители, страна пивоварни, упаковка или подача, «Пробовал / Не пробовал», диапазоны ABV/IBU/цены, порог оценки и доступность. Условия одной группы объединяются через OR, группы через AND. Выбранное семейство включает все его подстили. Для IPA используется собственная таблица точных нормализованных имён и синонимов с устойчивыми ID. Неизвестный стиль с catalog styleId остаётся отдельным вариантом. Подтверждённые возможности Untappd и границы сравнения перечислены в [аудите](P8.6_01_ARCHITECTURE.md#что-подтверждено-у-untappd).

Движок обрабатывает полную опубликованную редакцию. Сходные упаковки не схлопываются. Данные «Пробовал» поставляет сервер для конкретного positionId из активных чекинов текущего аккаунта, включая историю за пределами первых 100 записей. Неизвестное значение исключается только при активном условии. Для цены пользователь задаёт валюту, сортировка группирует цены по валютам. Обменные курсы не применяются.

Сортировки: порядок публикации, название, стиль, пивоварня, ABV и IBU в обоих направлениях, рейтинг, цена, непробованные, локальная релевантность при наличии совпадений. Последняя использует существующий LocalDiscovery и доступную историю на устройстве, для отсутствующих результатов используется видимый рейтинг. Неизвестные значения идут в конце сортировки по соответствующему полю, равенства разрешает positionId. При нестандартной сортировке позиции ранжируются между секциями.

Активные условия удаляются чипами. Диалог поддерживает редактирование, сброс и применение, пустая выдача предлагает снять конкретное условие. Временные параметры сохраняются при возврате из карточки в меню. Автоматические тесты движка находятся в `MenuFilterTest`, проверка маршрута и раскладки на устройстве отмечена в [передаче](P8.6_HANDOFF.md).
