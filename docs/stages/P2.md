## Архитектурные границы

P2 реализует серверные примитивы, проверяемые настоящими тестовыми данными.
Нет фиктивных production users/catalog/venues, dev endpoints в публичном API,
заглушек social/map/badges. Нереализованные маршруты возвращают 404.
Схема этих доменов не означает готовые продуктовые сценарии P4–P7.
Результаты A19/A20 и отдельных foundation checks фиксируются точно;
все 43 полных продуктовых E2E не объявляются пройденными по серверному smoke.

Рост 500k+ registered — цель. Один модульный монолит, PostgreSQL, индексы,
ограниченные запросы и файлы отдельно. Load/capacity утверждения возможны
только после измерений; не добавлять брокер/реплики/микросервисы заранее.
