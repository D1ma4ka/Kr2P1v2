## Что реализовано

- MapLibre Native Android 11.13.5 внутри Compose AndroidView: pan/zoom, локальный
  GeoJSON clustering с фактическими числовыми метками, zoom по нажатию, отдельные
  типы bar/beer_shop; viewport→bbox API с debounce/cancellation/generation guard.
  Локальные подписи кластеров не требуют внешнего glyph API. Lifecycle MapView
  поддерживает create/start/resume/pause/stop/destroy.
- Один набор фильтров поиска/города/типа для карты и списка; bounded map≤500 с
  truncated и предложением zoom, keyset list≤50. Антимеридиан обрабатывается.
  Ручной город, coarse location только по явному действию, без фонового tracking.
  Ошибка SDK/тайлов или пустой provider config дают объяснение и fallback-список.
- Метка → краткая карточка → полный профиль места с provenance, адресом, разрешённым
  фото и настоящим viewer-visible рейтингом; список→центрирование на карте.
  Из места можно начать чекин, выбрать позицию и сохранить venueId. Редактор имеет
  поиск по справочнику; свободный текст помечен «не подтверждено» и не создаёт точку.
  Существующая карточка чекина ведёт к месту. Общие пять вкладок П6.1 сохранены;
  рабочие входы есть на Главной, в Коллекции и Профиле.
- Десять versioned badge rules по семи SQL-метрикам: checkins, distinct positions,
  styles, breweries, notes, photos, venues. Полученные/неполученные, условие,
  progress, максимум три earned pins и изменение порядка; чужому профилю доступно
  только добровольное закрепление после ACL. Reconciliation идемпотентна, отзывает
  достижения/закрепления по актуальной истории, inactive rules исключены из счётчика.
  Точные цели — документированное решение v1 из разрешённой ТЗ области, не
  «исторически восстановленные» значения: [ADR-0010](../decisions/ADR-0010-P7-map-badges-moderation.md).
- Жалобы из Android на публичный user/checkin/comment/venue/position, устойчивый
  UUID/exact retry и reason. Сервер проверяет публичность и роли; rate budget.
  Защищённые admin API: список/чтение/создание/редактирование заведений,
  review queue, hide/restore/dismiss, роли и audit. Restore не отменяет удаление
  и не публикует pending/merged контент; user hide отзывает сессии.
- Совместимая additive migration010, readiness и OpenAPI. Старые venue UUID и
  checkins остаются; старые координаты без source не становятся «проверенными».
  Непубличные данные и tokens не передаются тайловому HTTP client.
  В APK включены MapLibre/OkHttp notices, доступные из настроек; attribution карты видна.

## Что не проверено и что осталось

1. В облаке нет `/dev/kvm` и подключённого устройства (`adb devices` пуст).
   Native GL rendering, жесты/pinch, cluster tap, provider recovery, permission denial,
   background/recreate, обе темы, 320dp/large font/TalkBack и полная новая Android
   регрессия **NOT RUN**. Новых runtime screenshots нет. Два адресных теста подготовлены;
   старые P6/P6.1 instrumented результаты не объявляются проверкой П7.
2. Запрос к OSM endpoint блокирует CONNECT proxy403 этой среды. Ни реальное
   отображение подложки здесь, ни доступность из России не подтверждены.
   SDK бесплатный/без ключа, но публичные OSM tiles используются только ограниченно
   в dev; production-провайдер/CDN/ключ не подключён и не куплен.
3. Справочник настоящих проверенных заведений не заполнен. Автоматических fake
   real-world seeds нет. Для проверки есть явные testOnly fixtures; Craft Republic
   из ТЗ пока только testOnly пример без координат/фото, не доказательство настоящего
   заведения. Внести подтверждённые данные можно через защищённый API.
4. Полная визуальная приёмка П6.1 также остаётся PENDING; текущая команда её не
   подменяет. Production и двухплатформенный продукт не объявляются готовыми.
