# P8.6.5 · Сравнение в меню

Действие «Сравнить» на строке меню добавляет её `positionId` к выбору текущего заведения. Кнопка «Сравнить (N)» открывает экран при 2–4 выбранных позициях. Можно снять выбор на строке, удалить позицию в сравнении или очистить список. При возврате из карточки или редактора чекина сохраняются выбор и активные фильтры. При смене заведения начинается новый выбор. При обновлении публикации из выбора исключаются исчезнувшие позиции.

Экран группирует значения по характеристике. В узком окне или при увеличенном шрифте значения идут вертикально, с подписью позиции и упаковки. Отличия между известными значениями обозначаются текстом и цветом. Пропущенные значения имеют подпись «Нет данных». Ноль личных чекинов отображается только при наличии подсчитанного значения. Кнопки открывают существующую карточку и редактор с текущим заведением и позицией. Редактор сохраняет черновик своим штатным путём.

Источник сравнения — один ответ `GET /v1/venues/:id/menu`. К существующим полям добавлены `description` выпуска, `ratedCheckins`, `personalCheckins` и `personalAverageRating`. Средняя оценка и число оценок отражают записи, видимые пользователю по прежним правилам. Личные поля считаются в той же выборке по владельцу сессии. Отдельные запросы для ячеек и строк отсутствуют. Старые сохранённые копии меню читаются, новые поля в них отображаются как отсутствующие. Формат таблиц PostgreSQL прежний.

Автоматические проверки покрыли 2–4 позиции, предел выбора, чужую позицию, одинаковые имена, разные упаковки, пропуски и видимость личных оценок. На этапе прошли серверный контракт и OpenAPI, Android debug APK, тестовый APK и JVM-тесты. Compose-тест 320 dp со шрифтом 150% и переключением темы скомпилирован. Запуск на устройстве, TalkBack и весь маршрут через настоящий редактор остались открыты.
