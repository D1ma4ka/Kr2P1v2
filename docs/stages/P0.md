recovery не сливали, старый APK не получали и не запускали. AGENTS не изменён;

## Фактическая проверка

Git 2.52.0, Python 3.12.14. Команда:

```sh
python3 scripts/verify_p0.py
```

Код выхода **0**:

```text
PASS: eight source documents match recorded sizes and SHA-256
PASS: baseline AGENTS unchanged; README introduction preserved
PASS: all 66 FR and 16 NFR mapped, priorities intact, 70 MUST
PASS: 22 screens, 12 planned E2E scenarios, 52 original acceptance checks
PASS: baseline contains no legacy files; working branch descends from baseline
P0 verification passed. Android/backend builds and product tests: NOT RUN.
```

Проверка выполнена один раз. Повторный запуск без изменения проверяемого
содержимого не требуется. Перед коммитом дополнительно проверяются staged
diff/status и whitespace командой `git diff --cached --check`.
Первый запуск diff-check вернул 2: десять Markdown hard breaks (два пробела
в конце строки) в исходных TECHNICAL_SPECIFICATION и SCREEN_MAP_AND_FLOWS.
Оригинальные байты сохранены; `.gitattributes` отключает только проверку
blank-at-eol для этих двух документов. Это основание для одного повторного
diff-check после настройки, без повторного запуска проверок матрицы.
Повторный `git diff --cached --check` завершился с кодом **0**; staged diff/status
просмотрены: 21 текстовый файл, без удаления файлов, без изменений AGENTS,
без APK, баз данных, изображений или секретов.
Ни Android/backend сборки, ни A1–A12 не запускались: исходников этих систем
ещё нет. CI P1 не создавался. Это не пропущенная проверка реализованной функции.

## Ошибки и ограничения

Ошибок целостности/полноты P0 не обнаружено. Замечание diff-check о смысловых
Markdown-переносах устранено настройкой выше. Блокеров завершения P0 нет.
Инженерные неопределённости (стек, точные badge rules, privacy/retention)
записаны в PROJECT_DECISIONS и решаются на соответствующих этапах.
Production-инфраструктура, юридический review и release signing не подтверждены;
они не препятствуют локальной разработке. Проверка SDK и сборок относится к P1.

`codex/krapiva-2-p0`; SHA и подтверждение remote приводятся в итоговом сообщении
после сохранения. Main и архивные ветки не изменяются. Merge, релиз и deployment
не выполняются.

Текущий этап: **P0**. Следующий: **P1 — clean foundation**.
По прямому уточнению владельца после сохранения и отчёта работа
**останавливается до сообщения «Продолжай»**. P1 не начат.
