## Исправлено в P8.6.7

- Маршрут меню зависел от `PlacesState.selected`. Карта очищает это поле при остановке и повторной загрузке. Теперь меню хранит ID и название места в состоянии своего навигационного запроса. При уходе в карточку и редактор состояние меню может восстановить существующий `SaveableStateProvider`. У карты один запуск на ON_START, загрузка карты на экране меню отключена. Возврат на реальном Android ждёт ретеста.
- Прямой переход из меню в карточку запускал инициализацию списка глобального каталога. Отдельный вход сразу открывает позицию и позволяет повторить чтение при ошибке. Обычный вход в каталог сохраняет свой список.
- В фильтрах отсутствовал диапазон объёма из F1. Добавлены границы в мл, съёмный чип, сохранение в собственных правилах и чтение старых правил с пустым диапазоном. Проверены включительные границы, пропуск неизвестного объёма, сброс и перенос между барами.
- Опубликованное пустое меню запускало загрузку истории. Теперь история нужна при наличии строк. После возврата приложения из фона открытый экран перезапрашивает меню и историю. Фильтрация больше не компилирует выражение нормализации пробелов для каждого имени.
- В стандартном наборе инструментальных проверок отсутствовали тесты Smart Bar. Включены проверки сравнения и хранилища. Добавлены проверки истечения TTL, инвалидирования и сохранности именованного правила, серверной атомарности и снятия верификации. Инструментальные проверки собраны.

## Как открыть последнюю версию в Android Studio

1. В чистом клоне выбрать `codex/krapiva-p8.6-smart-bar`, затем выполнить `git pull --ff-only`. При наличии собственных правок использовать отдельную рабочую копию. Проверить `git rev-parse HEAD`.
2. Подготовить локальный dev API по инструкции репозитория. После запуска проверить `http://127.0.0.1:53000/health/ready`. Для регистрации письмо приходит в локальный Mailpit. [Локальный backend](../DEPLOYMENT_RU.md)
3. Открыть каталог `android/` в Android Studio, выбрать JDK 21 для Gradle, установить Android SDK 35 и Build Tools 35.0.0, выполнить Sync. Выбрать модуль `app`, вариант `debug` и изолированный AVD API 26 либо 33+. По умолчанию debug-клиент обращается к `http://10.0.2.2:53000/`.
4. Для повторения с двумя заполненными **тестовыми** меню можно отдельно запустить стенд этого прогона. Из `backend/` после `npm ci` и `npm run build` задать локальный `TEST_DATABASE_URL` сервера PostgreSQL с правом создавать временные БД и выполнить `node dist/test/smart-bar-stand.js` в интерактивном терминале. Он печатает loopback-адрес со свободным портом. Оставить терминал открытым. Для эмулятора передать процессу Android Studio `KRAPIVA_DEV_API_BASE_URL=http://10.0.2.2:ПОРТ/` с напечатанным номером, пересобрать debug и войти тестовым посетителем из `SmartBarJourneyTest`. Места A и B находятся в городе QA. После испытания EOF в терминале закрывает временную базу стенда. В обычном dev API ассортимент появляется после публикации оператором.
5. На разрешённом тестовом телефоне использовать `adb reverse tcp:53000 tcp:53000` и debug-сборку с `KRAPIVA_DEV_API_BASE_URL=http://127.0.0.1:53000/`. Для временного стенда заменить оба порта его фактическим номером. При несовместимой подписи установленного пакета выбрать чистый тестовый телефон или AVD, сохранив приложение и данные владельца. Полный маршрут и критерии устройства приведены в [протоколе](P8.6_ACCEPTANCE.md).
