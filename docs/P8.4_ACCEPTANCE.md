# P8.4 — ручная приёмка кандидата

Новые разделы доступны из «Коллекция» и собственного профиля. Пять основных
вкладок сохранены. Нужен аккаунт с ранее загруженными реальными данными. Тестовые
данные новых Android-тестов изолированы; backend для них не нужен. В release
нет showcase, synthetic пользователей или обхода регистрации.

Все пункты ниже **PENDING** до реального выполнения на Android. Повторить обе
темы, 320dp/крупный системный шрифт/TalkBack; фото и permissions проверить на
минимальном API26 и Android13+.

1. **F1**: существующая позиция → чекин. Оценка 0,25/5,00/без оценки, теги,
   своя подача, четыре фото/удаление/повторный выбор, заметка/дата/visibility.
   Сразу выйти, затем открыть черновик; поворот/force-stop/перезапуск. Отключить
   сеть перед проверкой каталога: последние поля должны остаться локально.
2. **F2**: создать две подборки, переименовать, добавить банку и бутылку по
   разным positionId, повторить добавление (без дубля), copy/move/reorder/remove.
   Удалить с подтверждением. Перезапуск; logout/login владельца и второго аккаунта.
   Wishlist и чекины не должны измениться.
3. **F3**: загрузить «Мои записи» (несколько страниц), открыть «Мой вкус» офлайн.
   Проверить ограничение охвата, nullable ratings, unique positions, теги и месяцы.
   Изменить/удалить свой чекин через сервер; перезагрузить доступную историю.
4. **F4**: открыть несколько реальных карточек и wishlist, затем «Открытия».
   У рекомендаций есть объяснение; нет выдуманных записей/рейтингов. На чистом
   кэше — содержательные пустые блоки и работающий переход в каталог.
5. **F5**: карточка → пивоварня, личные агрегаты, собственная история/пагинация,
   собственный чекин, wishlist и подборки. Нет фото/средней → корректный fallback.
   Упаковки не объединяются по названию.
6. **F6**: явно выбрать год и timezone (UTC/Europe/Istanbul), проверить запись
   на границе года и leap day. Пустой год; длинные названия. Изображение должно
   совпадать с preview, открываться в Sharesheet без сети и storage permissions.
7. **F7**: earned/locked/категории/пустая категория/пины (до трёх)/порядок.
   Отключить анимации Android: нет reveal. Офлайн — пометка stale, изменение
   закреплений отключено; локальные чекины не присваивают server badges.
8. **F8**: «Уведомления» → явное планирование. Разрешить/запретить Android13+
   permission, системно отключить канал, выключить reminders в приложении,
   cancel/delete/read. Проверить реальную доставку после задержки/Doze/reboot,
   background/убитый процесс и открытие раздела. Другой аккаунт не должен видеть
   локальные события владельца; системный текст не содержит личных данных.
9. **F9**: query history, clear, recent positions, style/brewery/packaging/ABV,
   IME Search и возврат, process restart, offline empty/error. После server403/404
   открытие недавней позиции не должно восстанавливать недоступную карточку.
10. **F10**: собственный сохранённый чекин → share. Заметка выключена по умолчанию,
    включение отдельно; фото есть/отсутствует; private/friends предупреждения.
    Preview → реальный PNG в выбранном приложении. Исходная privacy не меняется,
    черновик не выдаётся за публикацию, публичная ссылка не появляется.

## Безопасная установка поверх P8.3

Сначала сравнить сертификаты старого и нового APK. Локальный P8.4 certificate
`5c32687c…f149c` отличается от опубликованного P8.3 download certificate
`f19a01e6…fe5e0` (docs/verification/p8.3/phone-download.json). Эти два
проверенных APK напрямую несовместимы для установки поверх друг друга. В этой новой среде прежний
приватный debug key отсутствовал; новый локальный/Actions debug APK может иметь
другую подпись. **При конфликте подписи не удалять установленное приложение и
его данные.** Для обновления нужен прежний signing key; иначе использовать
отдельное чистое тестовое устройство/профиль. Signing configuration не менялась.

Min Android 8.0 (API26); applicationId debug `ru.krapiva.app.debug`. Backend не
развёрнут: debug API сохраняет development configuration; offline вход возможен
при уже сохранённой сессии/профиле. Для новых реальных аккаунтов нужен существующий
сервер, регистрация не обходится. На физическом телефоне emulator localhost URL
не станет доступным сервером автоматически.

## Изолированные тесты без сервера

```sh
cd android
./gradlew --no-daemon assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest
# Только на доступном тестовом устройстве/эмуляторе:
./gradlew --no-daemon -Pandroid.testInstrumentationRunnerArguments.class=ru.krapiva.app.offline.EditorOfflineTest,ru.krapiva.app.offline.LocalStorageTest,ru.krapiva.app.offline.ShareImageTest,ru.krapiva.app.offline.RemindersTest connectedDebugAndroidTest
```

Эти тесты скомпилированы; выполнение не заявляется. Полная историческая P3 suite
требует прежних backend fixtures и не подменяется этими offline тестами.
