# Яндекс Карты в KraPiva

## Подключение для владельца

1. Войдите с Яндекс ID владельца проекта в [кабинет разработчика](https://developer.tech.yandex.ru/). Выберите «Подключить API» → «MapKit — мобильный SDK». Введите сведения о мобильном приложении. Для бесплатного плана проверьте условия ниже. Если кабинет предлагает оплату, прервите оформление до отдельного решения.
2. Скопируйте ключ из раздела «Интерфейсы API» → MapKit. Активация обычно занимает около 15 минут. В кабинете проверьте доступные ограничения ключа для своего приложения. Идентификаторы сборок KraPiva — `ru.krapiva.app.debug`, `ru.krapiva.app.staging` и `ru.krapiva.app`. [Инструкция Яндекса для Android](https://yandex.ru/maps-api/docs/mapkit/android/generated/getting_started.html)
3. Добавьте в **существующий** `android/local.properties` строку `MAPKIT_API_KEY=<значение из кабинета>`, сохранив остальные свойства. Файл исключён из Git. Для CI передайте значение через защищённую переменную окружения `MAPKIT_API_KEY`. Переменная окружения имеет приоритет. Оставляйте поле пустым для сборки без карты. Не вставляйте значение в команды shell, тикеты, APK-отчёты или вывод Gradle. Клиентский ключ присутствует в собранном приложении, поэтому владелец контролирует его ограничения и расход в кабинете.
4. Пересоберите нужный вариант. Для локальной проверки из `android/` выполните `./gradlew :app:assembleDebug`. Откройте «Места и карта», выберите город или разрешите геолокацию. Проверьте загрузку подложки, видимость логотипа, панорамирование, кластер, выбор отдельной метки, карточку, меню и события. Без ключа после выбора точки поиска доступны список, расстояния, радиусы и карточки. Для данных каталога нужен доступ к backend KraPiva.

## Данные и выбор SDK

KraPiva использует `com.yandex.android:maps.mobile:4.45.0-lite` для подложки, жестов, меток и кластеров. Системный Android LocationManager предоставляет координаты устройства. Fastify и PostgreSQL отвечают за каталог, расстояния, меню и события. Поиск организаций, геокодирование и маршрутизация Яндекса для этого сценария не требуются. Ручной поиск городов использует справочник каталога и существующий набор GeoNames с атрибуцией в настройках. [Возможности Lite и Full](https://yandex.ru/maps-api/products/mapkit)

Логотип и атрибуция остаются на карте. Ссылка на условия доступна в «Настройки» → «Лицензии и источники». Не копируйте тайлы, адреса, фотографии или результаты поиска Яндекса в собственную БД и не публикуйте снимки подложки как собственные карты. Данные заведений для KraPiva вносите через существующий модерируемый каталог с независимым подтверждённым источником. Эти HTTP-контракты пригодны для iOS и Business.
