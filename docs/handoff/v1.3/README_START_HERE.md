# KraPiva 2.0 — пакет обновления ТЗ v1.3

Этот пакет заменяет v1.2 для текущего проекта **D1ma4ka/Kr2P1v2**.

Содержимое:
- `docs/TECHNICAL_SPECIFICATION.md` — **полное** ТЗ v1.3, включая все прежние требования Android/backend/дизайн/motion и обязательный iOS-трек P10–P13.
- `codex/CODEX_CHANGES_v1.3.md` — инструкция для существующей задачи Codex, как безопасно внедрить изменения.
- `docs/design/reference/krapiva-dark-concept.png` — предоставленный владельцем визуальный референс (не production-актив).

**Как передать:** прикрепить ZIP к **той же** задаче Codex и отправить текст из `codex/CODEX_CHANGES_v1.3.md` (либо попросить Codex открыть этот файл). Не отправлять отдельные старые v1.2 обновления после v1.3.

Главное изменение: **iOS обязательна**, но она реализуется после Android в отдельном согласованном треке, без немедленного переписывания P2 под KMP.
