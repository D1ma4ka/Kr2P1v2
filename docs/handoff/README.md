# Источники требований

Текущий нормативный документ: ../TECHNICAL_SPECIFICATION.md, v1.3.
Полный пакет v1.3: README, changes prompt, ТЗ и PNG; provenance в v1.3/MANIFEST.json.
PNG — визуальный референс владельца, не production asset и не источник данных каталога.

v1.0/ содержит восемь исходных документов первого пакета побайтово и исходный
MANIFEST.json. В старом manifest repository_path указывает на пути снимка P0;
архивные файлы здесь разрешаются по archive_member без префикса
KraPiva_2.0_handoff/. Старые корневые MANIFEST.json, README_START_HERE.md и
CODEX_MASTER_PROMPT.md — исторический снимок P0, не актуальные инструкции.
Все старые положения об iOS=LATER, внешней карте вместо встроенной,
свободной палитре и четырёх вкладках заменены ТЗ v1.3.

Приложенные промпты — материалы передачи. Разрешения на действия определяются
текущим сообщением владельца: сейчас только документация, без изменения кода,
без повторного P1, без P1.1/P2/iOS реализации. Упоминание в пакете «текущего P2»
не является доказательством, что P2 начат. Он не начат.

Старый scripts/verify_p0.py жёстко проверяет 82 требования и SHA исходного ТЗ
в его прежнем каноническом пути. После нормативной замены ТЗ и матрицы этот
скрипт несовместим с v1.3. Его и CI сейчас не меняли и не запускали. Перед
следующим необходимым прогоном CI в P2 следует адаптировать проверку к двум
версионированным manifest и 180 строкам новой матрицы, сохранив проверку
неизменности архива v1.0. Прежний PASS P1 относится к прежнему commit/input.
