# KraPiva 2.0 — бриф бренда и дизайн-системы

## Что утверждено

Продукт — социальная платформа для взрослых ценителей **craft beer**. Логотип, иконка, стандартный аватар и весь визуальный язык должны сразу восприниматься как часть **крафтовой пивной культуры**. Название — `KraPiva` / «Крапива», но образ **растения крапивы запрещён как основа символики**. Не копировать логотип, палитру и интерфейс Untappd.

## Предлагаемое направление (дизайн-решение, а не утверждённый макет)

**«Пивной отпечаток» / Craft Mark:** компактный выразительный геометрический знак, объединяющий пинту/бокал с пеной и ощущение авторской этикетки. Не использовать лист, стебель или ботанические прожилки. Буквенный логотип KraPiva с читаемой формой букв на кириллице/латинице, без прямого совпадения с чужими товарными знаками.

- **Колорит (референс):** густая тёмная основа + медовый/янтарный акцент + светлая кремовая типографика; исторические `#111310`, `#F4B45E`, `#F5EEE4` — отправная точка, не жёсткий брендбук.
- **Образ:** крафтовая банка, пивной бар, дегустационная карточка, современная типографика, пиктограммы на основе бокала/бочки/крана, тактильные детали этикеток.
- **Не использовать:** растения/крапиву, мультяшного пьяного персонажа, агрессивную рекламу употребления алкоголя, эстетическое копирование Untappd.
- **Аватар по умолчанию:** нейтральная персона-заглушка или абстрактная фирменная метка, которая не подменяет фото реального пользователя.
- **Иконки значков:** 10 оригинальных достижений, интуитивные условия; первую награду переименовать из «Первый лист» в пивную нейтральную, сохраняя условие первого чекина.

## Выходные материалы

1. Оригинальный векторный логотип SVG + экспорт PNG для документации и UI.
2. Android adaptive icon (foreground + background), launcher icons разных плотностей, splash ресурс.
3. Фирменный аватар placeholder, стиль иконок значков.
4. Design tokens: colors, typography, spacing, shape, state.
5. Минимум 5 реальных Android скриншотов: onboarding, каталог, карточка позиции, чекин, социальная лента, профиль (можно больше).
6. Проверка читабельности, accessibility, тёмной темы, контрастности, небольших экранов.

Внутренний Dev-only mock-контент допустим на скриншотах при подписи **«демонстрационные данные / staging»**. Не создавать фиктивные публичные карточки «реальных» напитков/баров в production.

## Критерий приёмки

Пользователь, видя иконку и первый экран, должен понять «крафтовое пиво, дневник и общение», а не «растение/ботаника». Логотип должен быть представлен **реальным проверенным графическим файлом**, а не описанием или заглушкой, и не должен визуально заимствовать защищённые элементы конкурента.
