# Передача П8.1

П8.1 добавил безопасное autosave черновиков и обязательную серверную проверку
похожих позиций до публикации. Коммит и ветка указаны в GitHub после проверки.

Критические инварианты:

- черновик никогда не публикуется автоматически;
- исходные данные и фото не удаляются при ошибке сети или сервера;
- logout сохраняет черновики владельца, а другой аккаунт их не видит;
- публикация использует прежний UUID/idempotency key и не создаёт дубль;
- непроверенная позиция остаётся в moderation workflow.

Автоматические проверки PASS перечислены в [отчёте P8.1](stages/P8.1.md).
Ручные device/reboot/update/offline проверки требуют Android-устройства и ещё
не объявлены пройденными.
