# Актуальный бренд-бриф — v1.3 / визуальная система v1.2

Нормативный источник — TECHNICAL_SPECIFICATION.md §8/16/17.
Визуальный референс владельца: design/reference/krapiva-dark-concept.png.
Исходный бриф v1.0 архивирован в handoff/v1.0/docs/BRAND_BRIEF.md.

Утверждена композиция, а не готовый production SVG: кремовый контур бокала
и пена, янтарное пиво, зелёная шишка хмеля внутри, четыре угла сканирования.
App icon — знак на графите; horizontal logo — знак слева, KraPiva справа.
Хмель обязателен как пивной ингредиент; лист крапивы/ботаническая идентичность
не допускаются. Перерисовать оригинально, не вырезать PNG и чужие обложки.

Графит #0B0D0F, cream #F5EBD8, amber #F5A623, hop green #78B936.
Современный sans-serif с кириллицей: лицензированные Manrope/Inter либо
системный fallback, без старой serif/ретро-эстетики. Подробные токены —
DESIGN_SYSTEM. Android/iOS используют единый бренд с нативными insets/UX.

Пять пунктов: Главная / Каталог / Чекин / Бары / Профиль.
Жидкость и пена реагируют на наклон в реальном loading и welcome/registration;
сам системный splash статичен. No-sensor fallback, Reduce Motion и lifecycle
обязательны. Не вводить задержку запуска ради эффекта.

Существующие P1 SVG/PNG/Compose tokens соответствуют прежнему брифу и пока
не обновлены. P1 DONE сохраняется; дальнейшее P1.1 — отдельно согласованный
UI-блок после P2. Сейчас меняются только документы.
