Дата 2026-11-04. Источник: TECHNICAL_SPECIFICATION.md, версия 1.3.
180 требований: 135 FR + 45 NFR; 174 MUST, 5 SHOULD, 1 LATER.
Номера FR имеют пропуски; отсутствующие требования не добавлялись.
P0/P1 остаются DONE как исторические этапы. Только NFR-001 имеет доказанный
DONE; новые дизайн/motion/iOS требования не считаются выполненными ресурсами P1.
