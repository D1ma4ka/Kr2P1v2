# Соответствие П8.4 актуальному ТЗ

База 83403b4. Источник каждой строки — одноимённый ID в [ТЗ v1.3](../TECHNICAL_SPECIFICATION.md), включая §§15–17 и дополнение П6.1. Исходная матрица используется как указатель требований, а не как результат этой проверки. [Лог нового прогона](evidence/backend-tests.txt).

PASS — выполнен указанный критерий в его слое. PARTIAL — есть свидетельство конкретного слоя, полноценная приёмка остаётся открытой. BLOCKED — нет необходимых условий для итоговой проверки. NOT TESTED — независимый тест этого критерия не выполнялся. FUTURE — отложенная часть. FAIL/MISSING применимы при конкретном нарушении. Проблемы UX, не нарушающие всё требование целиком, вынесены в бэклог.
