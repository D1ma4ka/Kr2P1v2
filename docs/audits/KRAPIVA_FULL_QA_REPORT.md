## Продолжение от e8078525, 20 ноября 2026

В новой среде обе удалённые ветки сверены с handoff. До запуска проверены различия между 03c5900, 83403b4 и e8078525. Исходники Android и backend совпадают. Прежние 42 серверных теста и пять скриншотов сохраняют привязку к исследуемой версии.

Заново подняты PostgreSQL 17 и Mailpit в отдельном Compose-проекте, собран backend, выполнена миграция и получен ответ готовности локального API на порту 53000. Создан синтетический взрослый профиль обычным запросом регистрации (HTTP 202). Код из перехваченного в Mailpit письма принят маршрутом verify-code (HTTP 204). Это подготовка учётной записи через API. Доказательства ввода и переходов в Android учитываются отдельно.

Закрытый Actions API вернул Forbidden при загрузке исходного APK. Для локальной сборки используется то же дерево Android и адрес из манифеста артефакта, http://127.0.0.1:53000/. На эмуляторе для такого адреса нужен обратный проброс порта. Новый профиль эмулятора изолирован от устройств владельца.

**Аварийная остановка по команде владельца.** Через HTTP с хоста дополнительно проверены вход (200), создание двух приватных тестовых чекинов (201, 201), повтор второго с прежним ключом (200 и тот же ID), ответ главной (200 и ровно две записи). В выборке есть запись без оценки на 29 февраля и запись на границе года для UTC и Europe/Istanbul. [Обезличенный журнал](evidence/resume-api.txt)

Программный эмулятор API 26 появился в ADB, выполнен проброс порта 53000. Сборка локального APK прервана до получения файла. Вход через Android, кадр главной и F1–F10 остаются открытыми. Новых багов, UI-подтверждений прежних замечаний и новых кадров в этой сессии нет. Сохранены прежние 12 замечаний, 5 кадров, 180 строк матрицы и 22 гипотезы. Backend, сборка, эмулятор и тестовые контейнеры остановлены. Тома сохранены.
