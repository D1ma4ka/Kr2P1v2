# Независимый QA-аудит KraPiva 2.0 · П8.4

Исследуемая версия `83403b47d3bdac67585cbda4181eea17923098c1`. Оценка относится к Android и локальному тестовому API. Предыдущие прогоны сохранены ниже в порядке их выполнения.

## Решение для владельца

**Предварительная готовность — закрытый QA со взрослыми тестировщиками и синтетическими данными под наблюдением.** Вход, чтение собственных записей, основной путь публикации и разграничение доступа на сервере подтверждены. Для самостоятельного пилота с личными аккаунтами нужны проверка отзыва доступа на устройстве после смены владельца, доступный путь очистки поиска и исправление лимита отменённых напоминаний. До проверки системного канала и доставки функцию напоминаний нельзя считать принятой. Процент соответствия ТЗ сам по себе не измеряет риск для тестировщика.

**П8.5:** можно планировать ограниченный этап исправлений и повторной приёмки, начинать его по отдельной команде. **П9:** переход преждевременен. Условия входа — независимый ретест P1 и ошибок приватности, успешные сценарии с двумя аккаунтами на устройстве, Android 13+ с системными ограничениями и перезагрузкой, проверка доступности и медиа на поддерживаемом телефоне. Готовность собственно эксплуатации затем оценивается по критериям этапа П9.

## Функциональность и соответствие

- Android сохраняет сессию и восстанавливает офлайн-черновик до публикации. Пять основных вкладок открывались. Сохранённый полный серверный прогон — 42/42. На двух новых аккаунтах отдельно проверены доступ друга ко всем четырём вложениям, приватный чекин, реакция, комментарий и отзыв прав. После прекращения дружбы обновление ленты и прямые запросы закрыли доступ. [Журнал API](evidence/final-two-accounts.txt)
- При пересчёте личной истории последняя версия записи вытесняет старую, запись без оценки учитывается в количестве, но пропускается при вычислении средней. Доменный тест охватывает високосный день и границу года в двух поясах. Локальные рекомендации вернули непробованную позицию с двумя причинами. Диаграмма получает все 20 интервалов, но часть не выводит. [Расчёты](evidence/final-domain.txt) · [KP-QA-013](KRAPIVA_BUG_BACKLOG.md)
- Работающие лишь частично сценарии включают управление напоминаниями, очистку истории поиска и правку чекина с похожей позицией. В текущем интерфейсе отсутствуют путь освобождения квоты после скрытых отмен и корректное применение нового выбора позиции в существующем чекине. Из функций будущих этапов отдельно учтены серверная синхронизация локальных подборок и кабинет заведения. [Приёмка П8.4](../P8.4_ACCEPTANCE.md) · [Матрица](KRAPIVA_TZ_COMPLIANCE.md)
- В 180 строках ТЗ — **7 PASS, 84 PARTIAL, 0 FAIL, 31 BLOCKED, 25 NOT TESTED, 33 FUTURE**. Среди 147 применимых охват свидетельствами составляет **91/147 (61,9%)**, полное подтверждение — **7/147 (4,8%)**. Ноль полных FAIL не отменяет дефектов отдельных критериев внутри PARTIAL и П8.4. [Методика и построчная матрица](KRAPIVA_TZ_COMPLIANCE.md)

## История проверок

### Первый промежуточный отчёт

Работа остановлена владельцем 20 ноября 2026 года. Исходная ветка codex/krapiva-p8.4-offline, HEAD 83403b47d3bdac67585cbda4181eea17923098c1. Ветка аудита audit/krapiva-qa-product-20261120. Оценка готовности всего продукта и рекомендация к внешнему тестированию остаются открытыми.

- **Сервер.** Собран TypeScript backend. Полный изолированный прогон на PostgreSQL и Mailpit завершился: 42 теста прошли, 0 ошибок и пропусков. Проверены в том числе регистрация и коды, отзыв доступа, чекины, статистика, каталог, социальные операции, миграции и OpenAPI. [Лог](evidence/backend-tests.txt)
- **Android.** На программном эмуляторе API 26 установлен GitHub APK из 03c5900a92989602df089d7a8c6fab499c5a6639. SHA-256 файла совпал с записью Actions. Получены изображения системного старта, тёмного приветствия, регистрации, светлого приветствия при 320dp и шрифте 150%, светлой формы входа. Использовались тестовые данные. Светлая тема задана через сохранённую настройку изолированной debug-установки. Доказательства успешного Android-входа до команды STOP не зафиксировано. [Кадры](screenshots) · [UX-разбор](KRAPIVA_UX_REVIEW.md)
- **Замечания.** В бэклоге 12 записей: P0 — 0, P1 — 1, P2 — 7, P3 — 4, P4 — 0. Это замечания разной степени доказанности, преимущественно по коду; для каждого указан способ воспроизведения. Наиболее серьёзное — скрытые отменённые напоминания могут исчерпать лимит владельца. Обнаружены также сохранение фразы после очистки истории и неверный источник признака свежести рейтинга. [Бэклог](KRAPIVA_BUG_BACKLOG.md)
- **ТЗ и продукт.** Составлены матрица по 180 FR/NFR и дополнениям, инвентарь маршрутов, оценка интерфейса и 22 продуктовые гипотезы с топ-5, тремя отличительными идеями и тремя предлагаемыми релизами. [Матрица](KRAPIVA_TZ_COMPLIANCE.md) · [Продуктовые возможности](KRAPIVA_PRODUCT_OPPORTUNITIES.md)

Это не подтверждённое падение KraPiva. Ручная приёмка авторизованных экранов, проверки камеры, TalkBack, доставки напоминаний, офлайн-повторов и полного пользовательского цикла не завершены. ## Продолжение от e8078525, 20 ноября 2026

В новой среде обе удалённые ветки сверены с handoff. До запуска проверены различия между 03c5900, 83403b4 и e8078525. Исходники Android и backend совпадают. Прежние 42 серверных теста и пять скриншотов сохраняют привязку к исследуемой версии.

Заново подняты PostgreSQL 17 и Mailpit в отдельном Compose-проекте, собран backend, выполнена миграция и получен ответ готовности локального API на порту 53000. Создан синтетический взрослый профиль обычным запросом регистрации (HTTP 202). Код из перехваченного в Mailpit письма принят маршрутом verify-code (HTTP 204). Это подготовка учётной записи через API. Доказательства ввода и переходов в Android учитываются отдельно.

Закрытый Actions API вернул Forbidden при загрузке исходного APK. Для локальной сборки используется то же дерево Android и адрес из манифеста артефакта, http://127.0.0.1:53000/. На эмуляторе для такого адреса нужен обратный проброс порта. Новый профиль эмулятора изолирован от устройств владельца.

**Аварийная остановка по команде владельца.** Через HTTP с хоста дополнительно проверены вход (200), создание двух приватных тестовых чекинов (201, 201), повтор второго с прежним ключом (200 и тот же ID), ответ главной (200 и ровно две записи). В выборке есть запись без оценки на 29 февраля и запись на границе года для UTC и Europe/Istanbul. [Обезличенный журнал](evidence/resume-api.txt)

Программный эмулятор API 26 появился в ADB, выполнен проброс порта 53000. Сборка локального APK прервана до получения файла. Вход через Android, кадр главной и F1–F10 остаются открытыми. Новых багов, UI-подтверждений прежних замечаний и новых кадров в этой сессии нет. Сохранены прежние 12 замечаний, 5 кадров, 180 строк матрицы и 22 гипотезы. Backend, сборка, эмулятор и тестовые контейнеры остановлены. Тома сохранены.

**Вход через Android — PASS.** Через «Войти» заполнены поля никнейма и пароля. После нажатия сервер подтвердил login, профиль и собственную главную (все HTTP 200). При загрузке самого AVD наблюдался ANR com.android.systemui; затем окно закрылось и приложение работало. [Обезличенный лог](evidence/android-ui-login.txt) · [Главная](screenshots/05-home.png)

У приватной записи видны предупреждение, опция включения заметки и предпросмотр PNG; системная передача открыла окно выбора разговора. Внешнему адресату ничего не отправлено. Видимость конкретной записи второго тестового пользователя, реакция и комментарий остаются открытыми. При проверке геолокации поверх карты появилось системное окно «System UI has stopped». Этот кадр не подтверждает сбой процесса KraPiva или результат отказа в разрешении. [Лента](screenshots/36-feed-light-empty.png) · [Системное окно](screenshots/33-system-ui-location.png)
