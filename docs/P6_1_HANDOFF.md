## Реальные данные и известные отклонения

Главная использует `/v1/me/home`, `/v1/feed?limit=1`, `/v1/friends?limit=50`, `/v1/users/:id`, media API и PUT/DELETE like. ABV не добавляется из выдуманных данных: ответ чекина его не содержит. Шестерёнка открывает реальные настройки вместо колокольчика макета. В `scripts/prepare_p61_fixture.mjs` есть локальный dev-only сценарий создания синтетических аккаунтов/дружбы/чекинов через действующие механизмы. Он не входит в APK. В прежней локальной БД такие фикстуры уже созданы: **не пересоздавать**, если `work/p61-android.json` существует. Credentials и фото аккаунтов не коммитятся.
