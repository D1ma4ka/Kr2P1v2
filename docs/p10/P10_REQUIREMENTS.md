# Матрица выполнения P10

Источник требований — ТЗ «P10 — KraPiva: виртуальные питомцы, интерактивная комната, кастомизация и KrapiCoin» из задания владельца. Статус «проверено» означает, что выполнена указанная проверка. Приёмка подсистемы требует Android и настоящего backend.

**Полностью закрыты 16 из 18 строк матрицы.** Для завершения проверки напечатанных кодов и производительности требуется физический телефон. Каждая строка имеет одинаковый вес, включая строки с несколькими разделами ТЗ. [Доказательства](P10_QA_REPORT.md) · [Аппаратная приёмка](P10_HARDWARE_QA.md)
