# Движения KraPet

Четыре исходных движения находятся в индивидуальных `rig.json`. [Общий набор](../../assets/pets/motion.json) добавляет 17 клипов. Контроллер Android выбирает idle-клипы с паузами, обрабатывает приоритеты действий, останавливается вместе с экраном и учитывает системный масштаб анимаций.

- Публикация каталога движений в APK выполняется сборкой из `assets/pets/`.
- Добавьте длительность и ключи именованных костей. При необходимости включите `hold` для сохранения последней позы. Варианты слоя переключаются по ключу `value`.
- Для нового варианта экспортируйте WebP, сохраните его смещение в координатах исходного рига и добавьте в `layers.<слой>.variants`. Варианты `soft`, `nibble`, `yawn` и `closed` для рта получены из утверждённых исходников каждого питомца.
- Событие Android выбирает имя клипа и его приоритет. Якорь экипировки и слой используют одну матрицу кости. Индивидуальная версия клипа в `rig.json` имеет приоритет над общей.

Оригиналы фронтальные. Перед добавлением бегущих и боковых поз, сильного сгибания конечностей и жестов с точным контактом нужны подходящие дополнительные изображения. В стартовых клипах движения к столу, наклон и еда реализованы средствами плоского рига. Прежний отчёт о прозрачных ресурсах хранится в [P10_PET_ART](P10_PET_ART.md).
