# Добавление предмета KraPet

Стартовый пакет состоит из 25 предметов экипировки, 10 позиций еды, 15 предметов интерьера и одного тестового сувенира. Источник пакета — [catalog.json](../../assets/pets/items/catalog.json).

1. Экспортируйте прозрачный однофреймовый WebP в папку `art/`. Импорт принимает изображения до 1024 × 1024 и до 1 МиБ.
2. Добавьте запись в JSON с устойчивым ASCII ID, названием, `kind`, категорией, редкостью, ценой, слотами, совместимыми питомцами и SHA-256. Список `compatiblePets: []` разрешает всех питомцев. Цена `null` оставляет предмет за пределами магазина. `enabled: false` снимает предмет с продажи и отключает новое размещение.
3. Для экипировки укажите `render.displayWidth` в пикселях рига и долевые `originX` и `originY`. `dx`, `dy`, `scale` и `rotation` корректируют посадку относительно персонального якоря. Проверьте кадр движения и обе темы. Для декора укажите совместимые места комнаты.
4. При обновлении файла увеличьте `assetVersion`. `series`, `partnerId`, `transferable`, `availableFrom` и `availableUntil` задают метаданные происхождения и доступности. Права на передачу экземпляров понадобятся при реализации обмена.
5. Из `backend/` выполните `npm run build`, затем `node --env-file=../.env dist/src/operations/pet-content.js ../assets/pets/items/catalog.json`. Команда применяет пакет целиком после проверки метаданных, MIME, декодирования и контрольных сумм. Используется `MIGRATION_DATABASE_URL`.

Сервер отдаёт метаданные и WebP по SHA-256. Установленный Android получает стандартные типы через каталог. При недоступном изображении остаются название и описание действия. Старые URL изображений продолжают обслуживаться по прежнему хешу.
