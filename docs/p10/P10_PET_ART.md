# Графика стартовых питомцев P10

Пять утверждённых PNG из архива сохранены в `assets/pets/originals/` побайтно. Точка входа для приложения — [каталог питомцев](../../assets/pets/catalog.json). Каждый каталог в `assets/pets/rigs/` содержит манифест, прозрачный портрет для статичного показа и послойные спрайты в WebP без потерь. При экспорте сохранён масштаб исходного холста 1254 × 1254. Прозрачные поля обрезаны по границам каждого спрайта, а манифест возвращает его в исходные координаты. Удалены фон и студийная тень. Тема задаётся фоном комнаты.

В послойной сборке есть корпус, два глаза, рот, две руки и две ноги. У каждого глаза есть полуприкрытая и закрытая фазы. Подвижные детали отделены по видимым контурам исходника. Под глазами, ртом и в местах соединения конечностей восстановлены локальные участки корпуса с использованием соседних цветов и текстур. Полностью собранная поза покоя совпадает с прозрачным портретом при композитинге в размере исходного холста.

## Подключение рига

| Поле | Как использовать |
| --- | --- |
| `canvas` | Логический холст в пикселях исходника. Начало координат сверху слева, ось Y направлена вниз. Все слои масштабировать вместе с холстом. |
| `neutral` | Один спрайт для списка, карточки и режима уменьшенного движения. |
| `bones` | Опорные точки движений в координатах холста в покое. У дочерней точки `parent` указывает на родителя. |
| `layers` | `src` относительно манифеста, `offset` левого верхнего угла, `size`, опорная точка `bone` и порядок отрисовки `depth`. `variants` подменяет спрайт и его геометрию. |
| `anchors` | Поименованные точки крепления. `position` в координатах холста в покое, `rotation` в градусах по часовой стрелке, `scale` и `depth` для отрисовки предмета. |
| `clips` | Длительность и ключи в миллисекундах. `x` и `y` измеряются в пикселях, `rotation` в градусах по часовой стрелке, `scaleX` и `scaleY` — множители. Числа интерполируются линейно, варианты спрайтов переключаются по ключу. Пропущенное поле в ключе принимает значение покоя. Для удерживаемой позы `holdFrom` отмечает конец входа в позу. Android проигрывает оставшийся короткий интервал с паузами до следующего события. |

Сначала рассчитайте текущую матрицу корня. Для каждой дочерней точки умножьте матрицу родителя на локальное преобразование вокруг её опорной точки. Накладывайте эту матрицу и на соответствующий слой питомца, и на предметы, закреплённые на той же точке. Для предмета после матрицы кости примените смещение до точки крепления, поворот, масштаб и обратное смещение на координаты посадки внутри спрайта. Используйте один кадр для всех слоёв и рисуйте по возрастанию `depth`. Например, часы на `wrist` наследуют и движение корпуса, и движение поднятой руки. У всех пяти питомцев параметры посадки индивидуальны.

[Эталон Canvas](../../tools/p10/rig.mjs) показывает вычисление матриц и порядок отрисовки. У модели предмета `fits` сопоставляет ID питомца со списком деталей. Каждая деталь задаёт `slot`, `src` и `origin` — точку посадки внутри своего изображения. При необходимости укажите `offset` в осях холста до поворота предмета, `rotation`, `scale` или `depth`. Для предметов с несколькими деталями можно назначить каждой свой слот и слой. Совместимость задаётся наличием записи для питомца. Слоты `torso_base` и `torso_outer` позволяют наложить верх одежды поверх базового слоя. Размеры и перекрытия конкретной модели одежды проверяются по её посадке.

## Замена и расширение

1. При замене спрайта сохраните его положение через `offset` и `size`. При изменении силуэта скорректируйте `pivot`, `anchors` и ключи движения в манифесте.
2. Для нового питомца положите новый исходник в `originals/`, экспортируйте набор прозрачных слоёв и зарегистрируйте манифест в `catalog.json` под новым стабильным ID.
3. Для одежды и аксессуаров добавьте файлы предмета и запишите посадку в `fits` по ID персонажа. Подвижные детали привязывайте к нужным слотам.
4. Для нового движения добавьте клип с ключами трансформаций и при необходимости новыми вариантами спрайтов. Клипы в каталоге данных можно проигрывать одним и тем же вычислителем поз.

## Ограничения 2D-исходников

У всех пяти питомцев есть 21 клип. Смена спрайтов передаёт моргание, жевание и зевок. Ключевые кадры смещают и поворачивают видимые части тела. После еды кисть приближается к лицу и обозначает вытирание рта. Фронтальный спрайт руки объединяет плечо, предплечье и кисть. Контур корпуса под рукой восстановлен только в пределах небольших смещений.

| Состояния | Послойная реализация и предел жеста |
| --- | --- |
| `idle`, `blink` | Небольшой масштаб корпуса и три фазы век. Оба глаза остаются во фронтальном ракурсе. |
| `look`, `stretch`, `yawn` | Наклон, подъём рук и вариант открытого рта. Для поворота лица и разворота плеч нужны новые ракурсы. |
| `scratch` | Кисть подходит к носу дугой. Точный контакт требует отдельной кисти и маски перед лицом. |
| `react`, `alternate`, `purchase`, `gift`, `celebrate` | Разные наклоны, подскоки и взмахи по событию. Глубокий присед и перенос веса требуют суставных слоёв ног. |
| `greet`, `return` | Взмах видимой рукой над корпусом. Дополнительный сгиб локтя требует отдельного предплечья. |
| `adjust_clothes`, `adjust_glasses`, `adjust_hat` | Питомец подводит кисть к предмету, а предмет остаётся на точке крепления. Изменение формы ткани и захват пальцами требуют контактных поз. |
| `inspect` | Наклон корпуса в сторону предмета. Видимый поворот в профиль требует дополнительного ракурса. |
| `sit`, `eat`, `wipe` | Короткая посадка к столу, моргание в удерживаемой позе, смена фаз рта, подвод кисти и возврат. Посадка и начало еды имеют одну геометрию корпуса. Точный контакт со стулом, столом и губами требует отдельных опорных кадров. |
| `appear` | Новый питомец появляется во фронтальной позе с масштабированием корпуса. |

| Питомец | Ограничение |
| --- | --- |
| Бутылочка | Блики стекла, пробка и контур корпуса привязаны к фронтальному ракурсу. Для поворота или переноса прозрачных бликов на одежду нужны отдельные исходные слои. |
| Крышечка | Зубцы и блики металла сведены вместе. Наклон в плоскости поддерживается, а для разворота боком нужны дополнительные ракурсы. |
| Хмель | Лапы частично скрыты листьями. Подвижность листьев по отдельности и широкий взмах требуют перекрывающихся слоёв листвы и всей лапы. |
| Крапивка | Мелкие жилки под глазами и скрытая часть лап восстановлены локально. Для крупных жестов и деформации всего листа нужны отдельные исходные слои. |
| Краник | Ручка, медальон, носик, капля и корпус сведены в одном ракурсе. Для вращения ручки и изменения формы капли нужны отдельные исходные изображения. |

Для точного касания рта нужны утверждённые кадры подхода кисти, контакта с губами и отвода руки, отдельные спрайты плеча, предплечья и кисти и маска перекрытия лица в контактном кадре. Для глубокого приседания, шага и танца с переносом веса нужны поза в три четверти, согнутые ноги с раздельными бедром, голенью и стопой, а также опорные кадры для сиденья и пола. Для ткани, которая меняет форму при сгибе, понадобятся отдельные слои рукавов или деформация. Жёсткие аксессуары наследуют движение существующих точек крепления.
