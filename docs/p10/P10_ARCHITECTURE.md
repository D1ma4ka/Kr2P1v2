# Архитектура KraPet

Android использует существующие аккаунты и нижнюю навигацию. Состояние питомца, комнаты, инвентаря и валюты принадлежит серверу. JSON API находится под `/v1/pets` и использует основную сессию KraPiva. Подтверждённое состояние кэшируется отдельно для каждого аккаунта.

Миграция 017 добавляет определения питомцев, владельцев, активную комнату, каталог, экземпляры, историю владения, экипировку, декор, кошелёк, конфигурацию и QR-выдачи. Частичный уникальный индекс защищает бесплатный выбор. PostgreSQL проверяет принадлежность активного питомца и экземпляров при размещении. Идемпотентность покупок и потребления привязана к владельцу и UUID действия. Публикация чекина и начисление используют одну транзакцию. Для действующей QR-награды хранятся хеш кода, сроки, тираж, партнёр, кампания и журнал получателей.

Принята рабочая база Android Compose и backend Fastify/PostgreSQL из P8.7.2. Подробности формата рига находятся в [P10_PET_ART](P10_PET_ART.md), правила баланса в [P10_ECONOMY_CONFIG](P10_ECONOMY_CONFIG.md).
