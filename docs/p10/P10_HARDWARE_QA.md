# P10 на физическом Android

Для проверки нужны устройство с камерой и слабый Android для замеров. Одно устройство может выполнить оба прогона. Запишите модель, API, объём ОЗУ, размер окна в dp, тип подключения и SHA-256 APK. Используйте синтетический аккаунт и изолированный стенд. [Подготовка стенда](P10_RECOVERY.md)

Подключите телефон кабелем с передачей данных, включите «Отладка по USB» и подтвердите запрос на экране. Выполните `adb devices -l` на компьютере, к которому подключён телефон. Готовое устройство имеет статус `device`. USB с вашего компьютера автоматически не передаётся в облачный стенд. Выполняйте команды ADB на компьютере с телефоном или в среде, где этот телефон уже виден через ADB.

## Напечатанные коды

Сначала установите подписанный APK и настройте `adb reverse tcp:53000 tcp:53000`. Права камеры выдаются при первом открытии сканера. Выберите питомца на тестовом аккаунте. Подготовьте новый тестовый код и лист для печати из корня репозитория.

```sh
mkdir -p work
(umask 077; cd backend && node --env-file=../.env dist/src/operations/pet-content.js --test-reward > ../work/p10-hardware-code.txt)
krapet_zxing=$(find "${GRADLE_USER_HOME:-$HOME/.gradle}/caches/modules-2/files-2.1/com.google.zxing/core/3.5.3" -type f -name core-3.5.3.jar -print -quit)
java -Djava.awt.headless=true --class-path "$krapet_zxing" tools/p10/PrintCodes.java work/p10-hardware-code.txt work/p10-print-codes.png
```

JAR входит в зависимости Android и появится в кэше после сборки. Код действует сутки. Печатайте лист без обрезания белых полей. Храните лист и файл кода на тестовом стенде.

1. В «Питомец → События» откройте «Сканировать QR». После считывания с листа проверьте заполнение формы и нажмите «Получить награду». Дождитесь реакции и проверьте один экземпляр в коллекции. Баланс KC сохраняется.
2. Повторно отсканируйте тот же QR и подтвердите. Ожидается сообщение «Эта награда уже в коллекции» и тот же единственный экземпляр.
3. Откройте товарный сканер и наведите камеру на напечатанный `4006381333931`. Ожидается обычный поиск GTIN. Если кода нет в каталоге стенда, приложение покажет «Позиция не найдена».
4. Проверьте, что QR в товарном сканере помечается как неподдерживаемый и не открывает ссылку, а GTIN на странице событий не заполняет поле награды.

## Слабое устройство

Проведите замеры в одном режиме питания, с одинаковой яркостью и сетью. Дождитесь завершения фоновой синхронизации. Для каждого холодного запуска выполните `adb shell am force-stop ru.krapiva.app.debug`, затем откройте приложение и вкладку «Питомец». Запишите отдельно время от открытия приложения до главной и от касания вкладки до появления питомца. Сделайте минимум три запуска и запишите медиану, разброс и условия сети. После онлайн-прогона проверьте холодный офлайн-запуск с ранее сохранённой комнатой.

```sh
adb shell dumpsys meminfo ru.krapiva.app.debug > work/p10-memory-home.txt
adb shell dumpsys gfxinfo ru.krapiva.app.debug reset
```

После сброса счётчика откройте KraRoom, оставьте её на 30 секунд и проверьте несколько реакций и угощение. Снимите `dumpsys gfxinfo ru.krapiva.app.debug framestats` и `dumpsys meminfo ru.krapiva.app.debug`. Затем выйдите из KraRoom, подождите 30 секунд и повторите `dumpsys meminfo`. Запишите total PSS для главной, комнаты и состояния после выхода, долю janky-кадров и длительность выборки.

Для фоновой проверки отдельно снимите счётчик кадров. Нажмите Home, дождитесь окончания перехода, сбросьте `gfxinfo` и через 10 секунд снимите его ещё раз. Ожидается 0 новых кадров процесса приложения во время стабильного фона. Повторите для перехода на другую вкладку и сверяйте отсутствие движения питомца по трассировке или профилировщику. При системном масштабе анимации 0 подтвердите статичную позу.

Для оценки батареи выполните два одинаковых интервала по 15 минут с отключённой зарядкой. Один на главной, второй в KraRoom с включёнными анимациями. Запишите уровень и, если доступен, `Charge counter` из `adb shell dumpsys battery` до и после каждого интервала. При отсутствии счётчика используйте доступный на устройстве профилировщик питания и запишите его название. Отдельно укажите подключение, яркость и температуру устройства.

Приложите измерения и результаты четырёх действий со сканером к отчёту P10. Отчёт камеры должен указывать, что оба кода считаны с бумаги. [Отчёт QA](P10_QA_REPORT.md)
