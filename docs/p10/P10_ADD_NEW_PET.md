# Добавление питомца

Подготовьте утверждённый PNG и поместите его в `assets/pets/originals/`. В каталоге `rigs/<id>/` экспортируйте прозрачный портрет, слои, альтернативные позы и манифест. [Формат манифеста](P10_PET_ART.md) описывает опорные точки, размеры, порядок слоёв и экипировку. У Android и сервера один устойчивый ID. Серверное определение хранится в `kra_pet_definitions`.

В `catalog.json` зарегистрируйте файл рига. Android включает эти ресурсы при сборке и загружает слои только выбранного питомца. После проверки новой сборки можно включить серверное определение с тем же ID, именем и описанием характера. Для бесплатного стартового выбора существующий API использует `starter=true` и `enabled=true` в `kra_pet_definitions`. Он по-прежнему выдаёт один стартовый экземпляр на аккаунт. Для других источников выдачи понадобится отдельное правило получения.

Проверьте совместимость одежды, границы анимаций и темы до включения определения. При изменении состава стартовых персонажей обновите проверки, которые фиксируют утверждённый набор из пяти питомцев.
