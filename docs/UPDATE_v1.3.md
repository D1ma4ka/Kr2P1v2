# Принятие ТЗ v1.3 — только документация

Дата: 2026-11-04. Сравнение выполнено с реально сохранённой v1.0 и кодом P1
на fbe95ba. Отдельные v1.1/v1.2 ранее в этой рабочей ветке не внедрялись;
полная v1.3 включает их требования. Пакет прочитан полностью: README,
полное ТЗ, пояснения CODEX_CHANGES и PNG 1536×1024. Manifest v1.3 хранит SHA-256.
Исторические исходные восемь документов v1.0 сохранены побайтово в handoff/v1.0.

Текущий запрос разрешает только принятие требований и документацию. Поручения
в приложенном промпте реализовать P2/P1.1 не являются разрешением на такие
действия. P0/P1 DONE, P2 не начат; новый дизайн не реализуется в этой задаче.

## Визуальный референс

Изучены бокал со светлым контуром/пеной, янтарной жидкостью и зелёной шишкой
хмеля, четыре угла сканирования; горизонтальная подпись KraPiva; графитовые
карточки, янтарный CTA, пять нижних пунктов, примеры home/detail/badges.
Допустимый хмель — ингредиент пивоварения, не запрещённый лист крапивы.
Числа 128/94/23, чужие обложки/профиль/примеры напитков не становятся данными
или лицензированными production assets. iPhone-мокап не требует имитировать
Dynamic Island на Android. PNG хранится только в docs/design/reference.

## Точки согласования и неоднозначности

- §16.5 сохраняет историческое упоминание «версия 1.2». Заголовок v1.3,
  контроль версий и §17 определяют актуальную полную редакцию; исходник не правился.
- §7.2 по-прежнему говорит «нет подтверждённого backend стека». Фактически
  P1 уже выбрал Node/TypeScript/Fastify в ADR-0002; обновление не отменяет
  решение. В P2 выбирать SQL/storage/migrations, не переписывать рабочий сервер.
- 500k registered и 1M/3M — совместимые сценарии роста, не одновременная
  нагрузка и не обещание обслужить её на текущем VPS. Порог замеров — ADR.
- Старый verifier/CI жёстко привязан к 82 строкам и прежним SHA в корне.
  Код проверки сейчас не менялся. В P2 потребуется совместимость с v1.3
  и архивным baseline до следующего необходимого CI-прогона. Это задача
  проверки документации, а не регрессия сохранённого приложения P1.
- Право на оплату карт/VPS/Apple, TestFlight upload, merge и публикацию не дано.
  Mac/Xcode/Apple доступы сейчас не проверяются; iOS PLANNED, не фиктивный PASS.

## Проверка этой задачи

Только документальные проверки: provenance обоих пакетов, 180 уникальных ID
и приоритеты, 29 экранов, 43 сценария, ссылки и перечень изменённых файлов.
Сборки/тесты приложения/CI не запускались, программный код, конфигурация,
исходные assets и AGENTS не менялись. Commit отчёта с [skip ci].
Следующий разрешаемый этап — P2 только после новой команды владельца.

Проверки этой сессии прошли: 4 файла пакета v1.3 и 8 архивных документов
v1.0 совпадают по SHA-256; матрица 180/174 MUST, 29 экранов и 43 сценария
полны; изменяются только README.md и docs/. Whitespace-проверка авторских
документов пройдена. У неизменённых исходников ТЗ/архива сохранены исходные
Markdown hard breaks и завершающая пустая строка; они исключены из whitespace
проверки, их целостность проверена контрольными суммами. AGENTS, application
code, scripts, workflows, build configs и production assets совпадают с HEAD P1.
