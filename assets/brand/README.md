# KraPiva — оригинальные ресурсы P1

Созданы для этого проекта: пинта с короной пены, собственное геометрическое
написание KRAPIVA и нейтральный аватар. Ни старые материалы, ни внешние фото,
stock/шрифты, ни элементы Untappd не использованы. Это предложенное оформление
для проверки владельцем, не утверждённый товарный знак или результат legal clearance.

`mark.svg`, `logo.svg`, `avatar.svg` — исходные векторы. PNG экспортируются
скриптом `scripts/export_brand.py`; символ Android соответствует `mark.svg`.
Все цвета и размеры — `tokens.json` и Android `designsystem/Theme.kt`.
Переносы/форма SVG не зависят от установленных шрифтов. Полноценные десять
иконок наград относятся к P7 после определения правил.
