# KraPiva — оригинальные ресурсы Dark v1.2, P3

Знак: кремовый бокал/пена, янтарное пиво, зелёная шишка хмеля с чешуйками,
четыре угла сканера. Горизонтальный wordmark: знак слева, KraPiva справа.
Оригинальные SVG/Canvas/vector paths созданы для проекта по утверждённой
композиции; референс не извлекался в production. Нет чужих фото/Untappd/старых
активов. Это не заключение о регистрации товарного знака.

`mark.svg`, `logo.svg`, `avatar.svg` — исходники; PNG экспортирует
`scripts/export_brand.py` (CairoSVG 2.8.2/Pillow 11.3.0). В wordmark использован
системный sans-serif, в Android — системный sans; отдельный font binary не
распространяется. Текст SVG может зависеть от доступного системного шрифта;
проверенный PNG сохранён. Tokens — `tokens.json`, Theme.kt — Android mapping.
Плотности launcher и safe area adaptive icon экспортированы отдельно;
monochrome использует платформенный tint. Десять иконок наград — P7.
